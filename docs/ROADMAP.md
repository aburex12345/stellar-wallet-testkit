# Roadmap

Roadmap items are directional, not commitments.

## 0.1 — Baseline

- Deterministic controller and Freighter-compatible adapter.
- Browser injection and runner-neutral module mock.
- Typed transaction assertions, presets, CLI, tests, and governance.

## 0.2 — Compatibility confidence

- Contract tests against pinned released Freighter API versions.
- Versioned compatibility matrix and deprecation policy.
- More detailed result-code and option validation.
- Browser tests in Chromium, Firefox, and WebKit.

## 0.3 — Soroban depth

- Auth-entry decode and assertion helpers.
- Contract method and argument assertions.
- Fee-bump and multi-source transaction helpers.
- Resource and footprint inspection where SDK APIs are stable.

## 0.4 — Ecosystem integrations

- Cypress and WebdriverIO adapters using the same serialized protocol.
- React hook testing example and minimal framework examples.
- Scenario composition and JSON schema.

## 1.0 criteria

- Two independent production dApps validate the API.
- Supported Freighter versions are contract-tested.
- Stable fake-signing semantics and documented compatibility policy.
- Maintainer succession and release automation are exercised.

The detailed, contributor-ready backlog is in [WAVE_ISSUES.md](WAVE_ISSUES.md).
